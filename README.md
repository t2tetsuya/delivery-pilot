# Delivery Pilot v2.2 Web

v2.1のインセンティブ対応に加えて、スクリーンショット取込 → 自動入力補助 → 分析を一連の流れにしました。

- Uber等のスクショ選択
- 対応ブラウザでは端末OCRを試行
- OCR文字から売上/インセンティブ/件数/稼働時間を抽出して入力欄へ反映
- 保存前に数値確認
- 今日/週/月/年/累計でインセンティブ込み集計
- 時給、件単価、時間帯・エリア、目標進捗の自動分析
- APIキー不要の端末内分析

注意: Safari/iPhoneではWeb標準のTextDetector OCRが利用できない場合があります。その場合も画像選択と文字貼り付けによる抽出は使えます。完全な画像OCRや外部生成AIによる文章分析には、将来バックエンド/API接続が必要です。
