# Delivery Pilot v2.19 AI

これまでの不具合対策をまとめた実用版。

## 取り込み
- 複数スクショをまとめて選択
- 過去日付のスクショに対応
- 日付・売上・インセンティブ・配達件数・稼働時間を一覧で直接修正可能
- 登録しない行はチェックを外せる
- 週合計など1日分ではない可能性が高い値を警告
- 極端に小さい/大きいOCR値を警告
- 警告が残る行は登録前に修正が必要

## データ保護
- 完全一致の二重登録を防止
- 同じ日付の既存データは上書き確認
- JSONバックアップ対応

## iPhone / 更新対策
- 大量スクショ処理の途中で短い待機を入れ、iPhoneで固まりにくく調整
- Service Workerをネット優先に変更
- 古いキャッシュを自動削除
- 毎回ビルド番号付きURLで更新確認
- 「最新版を確認」ボタンからキャッシュ削除＋再読込
- GitHub Pages反映後にホーム画面版が古いまま残る問題を軽減

## 注意
OCRは100%ではありません。誤読時は一覧の数字をその場で直してから登録してください。
