# Delivery Pilot v2.21 AI

13枚のUber実画像を基準にOCR処理を修正。

## 主な修正
- 円記号が「\」に誤読されるケースに対応
- 4,334 / 4.334 / 4 334 のような金額表記ゆれに対応
- 明細の「売り上げ総額」が読めない時、週見出し直後の大きな金額を総額として使用
- 配達報酬 = 正味の料金 + チップ
- インセンティブ = プロモーション
- プロモーションが読めれば、総額−プロモーションから配達報酬を復元
- 配達報酬 + インセンティブ と画面の売上総額を照合
- 合計不一致は自動で要確認
- 週合計（長時間・多数件）は日別登録から除外
- 要確認が残っていても正常行だけ登録可能
- v2.20までのキャッシュ更新対策を継続
