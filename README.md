# Delivery Pilot v2.12 AI

iPhone Safari / GitHub Pages向け無料テスト版。

## v2.12の主な変更
- Uberスクリーンショットを複数選択して一括OCR
- 1日分だけでなく、過去の1か月分などをまとめて取り込み可能
- 各スクショを日付ごとに整理
- 日付・売上・インセンティブ・配達件数・オンライン時間を登録候補として確認
- 読み取りできないスクショは勝手に登録せず「要確認」に分離
- 同一データの二重登録をスキップ
- 同じ日付の既存データは上書き確認
- 週表示では青い選択日を画像から判定
- 配達報酬＝正味の料金＋チップ、インセンティブ＝プロモーション
- 確認できた候補だけ一括登録

## 注意
初回OCR時はTesseract.jsの言語データ取得のため通信が必要です。
OCR結果は誤認識する可能性があるため、一括登録前の確認を推奨します。
