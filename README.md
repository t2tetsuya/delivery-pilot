# Delivery Pilot v2.11 AI

## v2.11 修正
- Uberの週表示ヘッダーがあっても、青い棒で選択されている1日を画像から判定して日付を自動入力します。
- 「正味の料金 + プロモーション + チップ」を分離して読み取り、総額と一致するよう登録します。
- 配達報酬 = 正味の料金 + チップ、インセンティブ = プロモーションとして反映します。
- 週表示でも選択日を特定できた場合は1日分として保存できます。
- 選択日を特定できない場合は、誤登録防止のため日別入力を消去して保存を無効化します。
- v2.10までのOCR、同一画像再選択、二重登録防止、Service Worker更新対策を維持します。
